Lexer

A lexer is a program that converts a sequence of characters into a sequence of tokens, which are the smallest units of meaning an a programming language. It is often the first phase of a compiler, processing input to identify elements like identifiers, operators and keywords

Functionality

Key roles

  • Tokenization: The lexer takes some source and turns it into meaningful tokens
  • First Phase of Compilation: It is typically the first step in the compilation process, preparing the input for further analysis

Types of Tokens

Types of tokens can include various elements, such as:

  • Identifiers (e.g., variable names)
  • Operators (e.g., +,-,*)
  • Keywords(e.g., if, else, return, for)
  • Grouping symbols (e.g., parentheses, brackets)
  • Data types (e.g., int, float)

Stages of Lexing

  • The lexer needs a source code to be tokenized, the lexer doesn't scan the whole file at the start, rather it scans as we go through
  • Every item/character in the source code will be scanned, the scan will check if the character is eather an operator, a digit, keyword, identifier, String, etc.
  • Once we now the type of the character, it is appended to an ArrayList of the type Token
  • This process will continue on until EOF (end of file)
