    Compiler Optimization Research

    This website documents the development of a custom compiler and the research conducted for my thesis.

    The main focus of the project is studying the impact of compiler optimizations and comparing their results with established compilers.

    Introduction

    Compiler optimization is the process of transforming a program in order to improve characteristics such as execution time, memory usage or generated code size, while preserving the program's behavior.

    This project aims to implement several optimization techniques in a custom compiler and measure their effects through controlled experiments.

    Objective

    The objective of this research is to investigate how different compiler optimizations affect the performance of generated programs.

    The results will be compared with optimization levels provided by established compilers such as GCC .

    Compiler

    The compiler is being developed from scratch. Its development is divided into several stages.

    Component Description Status

    Experiments

    Experiments will be used to measure the effect of individual optimization techniques.

    Experiment 001 — Constant Folding

    Evaluates constant expressions at compile time and replaces them with the computed result (for example replacing 3 * 2 with 6) Measure the effect of evaluating constant expressions during compilation rather than during program execution.

    Status: Planned

    Experiment 002 — Dead Code Elimination

    Removes code that does not affect the program's results, helping to reduce the program size and improve performance

    Status: Planned

    Experiment 003 — Loop-invariant code motion

    Moves code that produces the same result in every iteration of a loop outside the loop itself

    Status: Planned

    Experiment 004 — Loop unrolling

    Eliminates the overhead associated with loop control and replaces the loop with multiple copies of its body

    Status: Planned

    Experiment 005 — auto-vectorization

    Converts scalar operations in loops into vector operations

    Status: Planned
